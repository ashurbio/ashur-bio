# بوابة قسم علوم الحياة — الكود المصدري

تطبيق ويب للقسم: جدول، إعلانات، امتحانات، محاضرات، غيابات، ولوحة للممثل.
الواجهة React (Vite)، والسيرفر وقاعدة البيانات على Supabase، والإيميلات عن طريق Brevo.

## محتويات المجلد

| المسار | شنو بيه |
|---|---|
| `web/` | كود الواجهة (الصفحات، التصميم، تسجيل الدخول) |
| `web/src/sb/config.js` | رابط مشروع Supabase والمفتاح العام (مسموح يكون علني، الحماية بقواعد RLS) |
| `web/src/sb/client.js` | الاتصال بالسيرفر وحفظ تسجيل الدخول |
| `web/src/sb/screens.jsx` | شاشات الطالب |
| `web/src/sb/admin.jsx` | لوحة الممثل |
| `web/src/fonts/` | الخطوط، منسوخة من Google Fonts وتنحمّل من موقعنا (رخصتها OFL بملف `LICENSE.txt`) |
| `supabase/functions/register` | إنشاء حساب ودز اسم المستخدم والرمز بالإيميل |
| `supabase/functions/reset-pin` | «نسيت الرمز» |
| `supabase/functions/mail-status` | فحص إعدادات الإيميل (يشتغل بس بمفتاح الاختبار) |
| `supabase/functions/study-ai` | «المترجم والملخّص»: يترجم أو يلخّص جزء من الملزمة عن طريق Claude |
| `web/src/sb/study/` | واجهة «المترجم والملخّص»: قراءة الملفات، تقسيمها، والنتائج والأسئلة |
| `supabase/functions/_shared/common.ts` | دوال مشتركة: نص الإيميل، الإرسال، الحد من المحاولات |
| `supabase/schema.sql` | قاعدة البيانات كاملة: الجداول، قواعد الأمان، الصلاحيات |

**ما بيه أي مفتاح سري.** مفتاح Brevo ورمز القسم محفوظين داخل قاعدة البيانات فقط.

## تشغيله على جهازك

يحتاج Node.js 18 أو أحدث.

```bash
cd web
npm install
npm run dev      # يفتح نسخة تجريبية على localhost
npm run build    # يطلع الموقع الجاهز بمجلد dist
```

## فحص التطبيق قبل النشر

مجلد `.claude/qa` بيه فحوصات تلقائية (Playwright) تشغّل كل الشاشات على سيرفر وهمي، وتفحص سهولة الاستخدام (axe) والسرعة (Lighthouse).
طريقة التشغيل مكتوبة بـ `.claude/qa/README.md`. ومجلد `.claude/skills` بيه مهارات Claude الخاصة بالتصميم والفحص والسرعة.

## تحديث الموقع المنشور (GitHub Pages)

1. `npm run build` داخل `web`.
2. انسخ محتويات `web/dist` إلى مستودع الموقع (تحذف مجلد `assets` القديم أول).
3. commit و push على فرع `main`.

## المترجم والملخّص (ترجمة الملازم وتلخيصها)

قسم بالتطبيق يرفع بيه الطالب ملزمة (PDF، صور، Word، PowerPoint، أو نص ملصوق) و:
- **يترجمها** للعربي (مع المصطلح الإنكليزي بين قوسين) أو للإنكليزي، صفحة بصفحة وبنفس الترتيب والجداول.
- أو **يلخّصها ويطلّع أسئلة**: الخلاصة والنقاط المهمة، المصطلحات، اختيار من متعدد، صح وخطأ، عدّد، علّل، قارن، املأ الفراغ، أسئلة مقالية — بثلاث مستويات (مختصر/متوسط/شامل) وبالعربي أو الإنكليزي أو الاثنين.
- كل نقطة وسؤال عليه رقم الصفحة حتى الطالب يراجعه بالملزمة. الأسئلة تفاعلية (يختار ويطلع له الصح والشرح)، ويكدر ينسخ أو ينزّل أو يطبع (PDF).

الملف ما ينحفظ بالخادم: المتصفح يقسّمه لأجزاء صغيرة ويدز كل جزء لدالة `study-ai`، وهي تدزه لـ Claude وترجع النتيجة أول بأول. النتائج تنحفظ على جهاز الطالب بس (لكل حساب لحاله).

### التفعيل (مرة وحدة)

1. سوّي مفتاح API من [console.anthropic.com](https://console.anthropic.com) واشحن رصيد، ويفضّل تحط حد صرف شهري من نفس الصفحة.
2. بـ Supabase: **Edge Functions → Secrets** أضف `ANTHROPIC_API_KEY` بقيمة المفتاح.
3. انشر الدالة: `supabase functions deploy study-ai --no-verify-jwt` (الدالة نفسها تتأكد من جلسة الطالب وإن حسابه فعّال).
4. ابنِ الموقع وانشره مثل العادة.

بدون المفتاح القسم يطلع للطلاب بس يكول «الميزة غير مفعّلة بعد».

### إعدادات اختيارية (Secrets بنفس المكان)

| الاسم | الافتراضي | شنو يسوي |
|---|---|---|
| `AI_MODEL` | `claude-opus-5-5` | النموذج. `claude-sonnet-5-5` بنص السعر تقريباً بس أقل دقة شوية |
| `AI_USER_DAILY` | `120` | عدد الأجزاء لكل طالب خلال 24 ساعة (الجزء = 1–4 صفحات) |
| `AI_GLOBAL_DAILY` | `1500` | عدد الأجزاء للقسم كله خلال 24 ساعة (سقف للكلفة) |
| `AI_TIME_LIMIT_SEC` | `135` | أقصى وقت لكل جزء. بالخطة المجانية لـ Supabase خليه 135، بالخطط المدفوعة ممكن لحد 380 |
| `AI_FALLBACKS` | `default` | إذا النموذج رفض جزء (يصير أحياناً بمواضيع الأحياء الدقيقة والفايروسات) يعيده على نموذج بديل. `off` يطفيها |

### الكلفة (تقريبية)

سعر `claude-opus-5-5`: ‏4$ لكل مليون توكن داخل و20$ لكل مليون توكن طالع. هذي أرقام تقديرية (الكلفة الحقيقية تعتمد على كثافة النص):
- **الترجمة:** حوالي 3–6 سنت للصفحة، يعني ملزمة 20 صفحة تقريباً دولار واحد.
- **مراجعة سريعة** (الخلاصة + اختيار من متعدد + صح وخطأ، مستوى متوسط): حوالي 3–6 سنت للصفحة.
- **كل الأنواع بمستوى شامل:** أغلى بكثير، ممكن توصل 15–30 سنت للصفحة.

سجلات الدالة (Edge Functions → study-ai → Logs) تبيّن عدد التوكنات لكل طلب، والصرف الحقيقي بـ Anthropic Console. حط حد صرف شهري هناك، و `AI_GLOBAL_DAILY` يحدد سقف يومي للقسم.

### فحص الدالة

```bash
deno test --allow-net --allow-env --allow-run --allow-read supabase/functions/tests/study-ai-test.ts
```
يشغّل الدالة الحقيقية على Supabase و Claude وهميين (ما يحتاج مفاتيح ولا إنترنت).

## إذا تريد تنقله لمشروع Supabase جديد

1. سوّي مشروع جديد بـ Supabase.
2. افتح SQL Editor، الصق `supabase/schema.sql`، وغيّر القيم بقسم «Initial data» بآخره (رمز القسم، إيميل المرسل، رابط التطبيق) قبل التشغيل.
3. انشر الدوال: `supabase functions deploy register reset-pin mail-status study-ai --no-verify-jwt`.
4. حط مفتاح Brevo إما بجدول `private.config` أو كـ secret باسم `BREVO_API_KEY`.
5. غيّر `SUPABASE_URL` و `SUPABASE_KEY` بملف `web/src/sb/config.js` لقيم المشروع الجديد، وابنِ الموقع من جديد.

أول حساب يتسجل بالمشروع الجديد يصير هو المالك.
